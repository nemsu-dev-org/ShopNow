# Getting Help

Thanks for using ShopNow! Here is how to get help.

## Before asking

1. **Check the setup guide.** Many common problems (missing modules, database errors, environment variables) are covered in the [Troubleshooting section of SETUP.md](SETUP.md#-troubleshooting).
2. **Search existing issues.** Your question may already be answered in an [open or closed issue](https://github.com/nemsu-dev-org/ShopNow/issues?q=is%3Aissue).

## Asking a question

If you still need help, [open a new issue](https://github.com/nemsu-dev-org/ShopNow/issues/new/choose). GitHub Discussions is not enabled, so issues are the place for questions.

To help us help you, include:

- What you were trying to do
- What happened instead, with any error messages
- Your OS, Python version and the steps you already tried

## Reporting a security vulnerability

Please **do not** open a public issue for security problems. Follow [SECURITY.md](SECURITY.md) instead.
